# AGENTS.md

This workspace is a second brain built and maintained by agents. Before doing anything, read `Vault/_system/RUN.md`. It tells you which role you are playing and which few files to load next; do not load the other manuals "just in case".

Hard rules, in case you read nothing else:

- `Raw/` folders and the user's code are read-only.
- Never mark a note `validated` yourself. The writer never audits its own work.
- Before creating or changing any knowledge note, read `Vault/_system/Editorial design.md` in full.
- Write to existing notes only through the validated write gate (`sc.ps1 escribir`), never by direct edit.
- Keep whatever model and effort the user selected.
