# second_brain toolkit

The command-line toolkit the agents call (`sc.py`, wrapped by `sc.ps1`): source inventory with SHA-256, page and transcript extraction, work packages with `cobertura.json`, figure cropping by caption (`figuras.py`), the validated write gate, the defined-terms checker, the ontology plan validator and a local MathJax preview.

Every command, flag and guarantee is documented in [`Vault/_system/Tools.md`](../../../Vault/_system/Tools.md). The code itself is not part of this release yet.
